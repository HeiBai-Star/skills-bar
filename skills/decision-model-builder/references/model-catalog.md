## 选择规则

先问模型要回答哪类问题：

| 决策问题 | 首选模型 | 关键输出 |
|---|---|---|
| 为什么发生？ | 问题树 + 假设树 + 因果图 | 可验证的原因假设 |
| 哪个方案整体更好？ | 多属性效用/加权评分 | 透明的价值权衡 |
| 风险下该不该做？ | 决策树 + 期望值 + 后悔值 | 概率加权结果与下行风险 |
| 先做什么？ | 价值—成本—风险；必要时 RICE/WSJF | 有约束的排序 |
| 资源怎么分？ | 约束优化 + 边际收益 | 每增加一单位资源的回报 |
| 现在决定还是先学习？ | 信息价值 + 实验 + 真实期权 | 学习价值和阶段闸门 |
| 哪些变化会推翻结论？ | 敏感性 + 情景 + 临界值 | 反转条件 |

只选能改变决策的模型。若简单的约束表即可排除多数方案，不要先建复杂评分模型。

## 诊断与因果模型

### 问题树与假设树

用于把结果差距拆成可验证驱动因素。尽量做到同一层级不重叠且合计覆盖主要解释，但不要为追求形式上的 MECE 切断真实交互。

步骤：

1. 定义结果差距、基准、时间和对象。
2. 按可计算关系拆分，例如 `利润 = 收入 - 成本`、`收入 = 客户数 × 客单价`。
3. 将每个分支改写为可证伪假设。
4. 按潜在影响、证据强度和验证成本排序。

### 因果图（DAG）

用于区分原因、结果、共同原因、中介和碰撞变量。每条箭头写成一句机制陈述：“X 通过 M 在 T 时间内影响 Y”。

检查：

- 是否把同时影响 X 与 Y 的共同原因遗漏？
- 是否错误控制中介或碰撞变量？
- 时间顺序是否支持因果方向？
- 是否存在反向因果、选择偏差或测量偏差？

相关性只能生成假设；要宣称因果，需实验、准实验或充分的识别策略。

## 方案比较模型

### 多属性效用/加权评分

适用于多个方案在多个独立标准间权衡，且不能用单一货币或效用指标统一表达的情况。

基本式：`总分(option) = Σ 标准权重_i × 效用分_i(option)`，其中权重和为 1。

构建规则：

- 先过滤硬约束，再评分。
- 用“摆动权重”定权：比较一个标准从最差变到最好有多重要，而不是问标准名称听起来多重要。
- 给 0、50、100 写可观察锚点；必要时使用非线性效用函数。
- 检查标准是否重复，例如“收入增长”和“市场份额”可能重复计入同一价值。
- 总分接近时优先说明差异来源，不宣称微小差距有统计意义。

不适用：只有一个主目标、方案受强依赖约束、评分无法可靠锚定，或极端下行风险会被平均分掩盖。

### 成本收益与净现值

当主要结果可合理货币化且跨时间发生时使用。

- `NPV = Σ CF_t / (1+r)^t - 初始投入`
- 同时展示现金流时间、折现率、残值和机会成本。
- 对难货币化的安全、声誉、公平或战略选项单独列示，不强行塞入金额。

## 风险与不确定性模型

### 决策树与期望值

用于结果路径、条件概率和后续选择清楚的序贯决策。

- `EV = Σ 概率_s × 结果_s`
- 概率来自频率、校准判断或范围；标明来源。
- 除期望值外，同时报告下行分位、最大损失、可逆性和流动性约束。

### 最小最大后悔

当概率不可靠但可描述多种未来状态时使用。

1. 对每个未来状态找出最佳结果。
2. 计算每个方案相对该最佳结果的后悔值。
3. 比较各方案的最大后悔。

它体现稳健偏好，不等于价值最大化；需说明为何采用这种风险态度。

### 敏感性与临界值

用于识别“结论依赖什么”。

- 单因素：一次只改变一个输入，便于解释局部影响。
- 情景：让逻辑相关的变量共同变化，避免不可能的组合。
- 临界值：求使两方案无差异的输入值或权重。
- 二阶：必要时测试变量相关性、非线性和交互作用。

不要只报告“上下浮动 10%”；范围应来自历史、机制或可辩护的边界。

## 优先级与资源分配模型

### 价值—成本—风险排序

适用于待办、产品机会或改进项目。至少纳入：增量价值、实现成本、成功概率、时间紧迫性、战略或依赖风险。

RICE、ICE、WSJF 可作速记框架，但必须重新定义字段和评分锚点。不要跨团队比较口径不同的分数。

### 约束优化与边际收益

当方案可组合且共享有限预算、时间或能力时使用。定义：

- 目标函数：最大化价值、覆盖、利润或风险下降
- 决策变量：每个项目选择与投入量
- 约束：预算、产能、依赖、最小投入、互斥和合规

比较边际收益，而非平均收益。注意项目不可分割、收益曲线递减和组合协同；这些条件会使简单“收益/成本”排序失效。

## 学习与阶段决策模型

### 信息价值（VoI）

估计额外信息是否值得获取：

`信息净价值 ≈ 获得信息后的期望决策价值 - 当前最佳决策价值 - 信息成本 - 延迟成本`

优先验证同时满足“高影响、低置信度、可低成本验证”的假设。不能改变行动的信息，其信息价值接近零。

### 实验与阶段闸门

将大而难逆转的承诺拆成试点、扩展和全面投入。每一阶段预先定义：

- 要验证的关键假设
- 领先指标与最低样本/观察期
- 继续、修改、停止阈值
- 最大可承受损失和退出机制

避免试验后再移动成功标准。

### 真实期权

当等待、扩展、收缩、切换或退出本身有价值时使用。高不确定、高上行、损失可封顶的方案常适合小额购买选择权，而非立即做全额承诺。

## 组合规则与常见误用

推荐组合：

- 因果图 → 找驱动因素；决策树 → 比较行动。
- 硬约束 → 排除不可行项；加权评分 → 比较剩余方案；敏感性 → 检查稳健性。
- 情景 → 构造一致未来；后悔值 → 选择稳健方案；阶段闸门 → 限制不可逆损失。

避免：

- 把同一因素同时计入概率和收益，造成重复惩罚或奖励。
- 用平均值掩盖尾部风险、现金流断裂或硬门槛。
- 将模型输出当作事实，不披露权重和价值判断。
- 看到复杂问题就做 Monte Carlo；输入没有校准时，更多随机数不会增加可信度。
- 因为数据可得就选择指标；优先选择能代表目标和因果机制的指标。
