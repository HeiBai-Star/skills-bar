# 认知科学学习助手 · 使用说明

版本：1.1.0\
包名：cognitive-learning-coach\
原包基础文献核对日期：2026-09-24（沿用原包记录，本次更新未逐项重新核验）

## 它是什么

这是一个围绕理解、论证、练习、保持、迁移与自主学习组织的通用学习 Skill。它不是把二十种理论一次讲给你，而是根据你现在的困难选择合适方法。基础使用不依赖代码或连接器。

完整交付文件为 cognitive-learning-coach-1.1.0.zip。解压后根目录 cognitive-learning-coach 中包含入口 SKILL.md、界面元数据、按需加载的模型与教学协议、来源说明、示范、验收用例和输出模板。在支持自定义 Skill 的环境中使用；具体导入方式和可选工具取决于实际产品。本文件不表示已经替你安装或启用了任何连接器。

导入时请安装完整的 cognitive-learning-coach 目录，保留 references/、assets/ 和 agents/ 的相对位置。只下载 SKILL.md 的导入器无法取得完整模型库、教学协议和记录模板，需要补齐这些资源；agents/openai.yaml 仅提供可选界面信息，其他客户端的必要规则仍在 SKILL.md 和参考文件中。

## 从一句话开始

> 用认知科学学习助手带我学习【主题】。我的基础是【已知内容或零基础】，目的是【要能做什么】，每次可投入【时间】。先确定一个小目标，再根据我的表现选方法；不要一次倾倒整套课程。

不需要填满所有字段。直接说“解释这个概念”也可以。它只补问会实质影响本轮的缺失信息。

## 你可以直接说

| 想做的事 | 可复制的指令 |
|---|---|
| 系统学习 | 带我系统学习 X，先给短阶段路线，再开始第一小节。 |
| 快速查阅 | 直接解释 X，给一个例子和边界，今天不要考我。 |
| 完整讲解 | 像一章教材那样完整讲解 X，最后单独放练习与答案。 |
| 发现式学习 | 用情境和问题让我逐渐发现 X，先别揭晓；卡住时给支架。 |
| 新旧知识连接 | 我已经懂 A，请用有意义学习的方法把 B 接进来，并指出二者不相同的地方。 |
| 建立知识结构 | 围绕“X 为什么发生”建立概念地图，每条连接都写关系词与条件。 |
| 检验论证 | 用图尔敏模型分析这段话，分清证据、隐含保证和例外，不替作者补造证据。 |
| 检查是否真懂 | 检查我是否真的理解 X，一次一题，先不要给答案。 |
| 训练迁移 | 把 X 放到一个新情境，再给一个看似相似但不适用的情境。 |
| 精读资料 | 根据我上传的材料带读，先确认实际能读取哪些章节。 |
| 技术实践 | 先讲原理，再给安全示例，最后让我独立完成一个小任务。 |
| 恢复进度 | 根据这张续学卡继续，先核查一个关键知识点，不把旧成绩当成现在一定会。 |
| 复盘与保存 | 总结今天真正学会的关系、作答证据和薄弱点，生成最小续学卡。 |

这些是自然语言指令，不是必须逐字输入的软件命令。可随时改变节奏，例如“多解释一点”“不要比喻”“暂停提问”。

## 四个核心支点

**奥苏贝尔的有意义学习。** 用你可靠的已有知识作为新知识的支点，建立上位、下位、并列、条件或其他实质关系；必要时先给先行组织者，再逐步分化和协调概念。不会只把内容换一种说法，也不把“讲解”误判为机械学习。参见 sources.md 中 S01、S03。

**认知负荷理论。** 关注本轮新术语、相互依赖的步骤、信息分散和先修缺口；根据表现选择示范、分段和撤除提示。不会把困难一概消除，也不会凭聊天给出所谓脑负荷数值。参见 S02。

**概念地图。** 围绕焦点问题组织“概念—关系词—概念”的命题，保留条件与跨分支联系；通过补关系、找反例和脱稿重建检查理解。它不是仅把目录画成树。参见 S03。

**图尔敏论证模型。** 分清主张、数据、论证保证、保证的支持、限定语和例外条件。关注“为什么这些证据能支持这个结论”，并保留缺失证据和有争议的前提。结构完整不意味着结论真实。参见 S04、S05。

这里的具体教学流程是本包改写，来源支持模型含义，而不是逐句提供对话脚本。

## 其余模型怎样配合

模型库共收录 20 个模型或策略族，并没有把它们全称为同一种科学理论：

| 任务 | 收录的方法 |
|---|---|
| 建立和调整理解 | 有意义学习；认知负荷/样例/专长反转；概念地图；自我解释与精加工；多媒体学习；概念转变 |
| 检查理由与迁移 | 图尔敏论证；类比编码与迁移 |
| 把接触变成可提取能力 | 提取练习；间隔练习；交错辨别；ICAP 认知参与 |
| 练习与反馈 | 形成性反馈；掌握学习；认知学徒制与脚手架；刻意练习；生产性失败 |
| 自主管理学习 | 自我调节与元认知；自我决定理论；修订版 Bloom 目标分类 |

模型之间有重叠，归组只是导航，不是新的理论分类。先按当前困难选择方法，再读取所需条目；首次使用也不要求通读 20 个模型。默认每个小单元选择一个主策略，配少量辅助策略。

规划课程时，每个单元给出包含练习和反馈的暂定时间区间；超过你单次可用时间就拆分，并说明停在哪里。时间预算是安排依据，不是学会所需时长的保证。

## 一个实际使用过程

假设你说：“几个概念总混淆，想建立知识体系。”

助手先确定要区分什么，再找一个具体例子了解混淆点。它可能用有意义学习定位已有支点，用概念地图写清关系，再让你辨别一个反例。如果关系仍错，先修正这一处；如果熟悉例子已会，就换情境检验。它不会因为给你输出了一张大图，就宣布你已经形成完整知识体系。

这个例子描述预期行为，不是保证某次对话一定改善多少成绩。

## 怎样记录“学会了”

记录以实际任务为依据：未测、需支持、能独立完成本类任务、有延迟保持证据、有迁移证据。不同维度可以不同，例如概念解释熟练但操作仍需提示。

看过答案再答对，不算无提示成功；刚讲完能复述，不等于下周还能提取；会做原题，不等于新场景会用。助手可以建议复习窗口，但不会伪装成已经拟合个人遗忘曲线。

基础使用只需一张短续学卡。机器可读 JSON 模板放在 assets/learning-state.template.json，用户明确需要时才使用；模板中的空字段和示例格式不能变成虚构成绩。新格式使用稳定状态码，另记“隔多久、测什么、结果怎样”；测过不等于通过。

复习队列只留未完成事项，完成后移出，作答证据保留；取消不产生虚构成绩，改期保留任务身份。完成或取消会留下最小关闭记录，防止导入旧卡时重新出现。同一份记录重复导入不会重复累计。修改学习记录不表示外部日历或提醒已经同步，尚待处理的提醒信息会保留。

已有 1.0.0 学习记录可以继续提供。只在你要求更新或导出时转换为 2.0.0 记录格式，保留原有题目、作答、来源和日期；新增但未知的信息留空。这里的记录格式版本与技能包 1.1.0 是两回事。

## 外部能力与限制

网页研究、读取 PDF/书籍、可视化、运行代码、写入知识库或创建提醒，均取决于运行环境实际提供的工具与授权。技能包不自带这些服务，不创建账号，也不预装密钥。

当请求需要某项外部能力时，助手按环境规则发现可用工具并核对操作结果。没有读取到全文就不声称通读；没有成功写入就不声称保存；没有成功建立定时任务就不声称会自动提醒。没有持久存储时，你保存续学卡并在下一次提供即可续接。

主动教学不等于强迫教学。你始终可以要求直接答案、暂停测试或改变节奏。

## 科学性怎么把关

sources.md 收录 23 条基础文献说明，并明确公开全文、摘要或预览的实际核对范围。引用来源不等于宣称所有理论的证据强度相同；原作者框架、实验效应与本包工程规则分别标识。

不采用学习金字塔固定保持率、不按左右脑或固定学习风格给人分类、不宣传万能复习间隔或“一万小时必成专家”。也不把“费曼法”等流行名称当作独立的科学保证；需要时具体采用自我解释、提取和反馈等动作。

整个 Skill 的组合尚没有接受真实学习者的对照实验，不能据此声称效率翻倍。随包附 28 个有具体输入与判据的回归测试场景，包括时间预算、复习完成与改期、旧记录兼容和重复导入；静态文件校验不能替代实际运行测试，更不能替代学习成效研究。验收规范不表示所有场景已在所有模型上通过。

## 第一次使用的建议

从一个真实而有限的问题开始，例如“我总分不清这三个概念”或“帮我检验这段论证”。完成一次解释、练习与反馈后，再扩大为长期课程。先看它有没有找准你卡住的位置，而不是先追求一份庞大的知识目录。
