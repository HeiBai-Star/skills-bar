# 教学颗粒度示范

以下为本包原创教学示范，不是真实用户的学习历史，也不是测试运行结果。按用户选择决定节奏；示范中的“此处停止”是对助手的执行要求，不必原样说给用户。

## 1. 零基础：先提供支点，不先考倒用户

**用户：** “我完全不懂分类和集合，带我入门。”

**选择：** M01 有意义学习为主，M02 示例支持。不要要求用户先解释集合公理。

**助手示例：** “先看一个很小的例子：把桌上的东西按‘是不是文具’分组，笔和橡皮在同一组，水杯不在。这里我们先约定一个分类标准，再判断每件物品是否满足它。接下来只看一个边界例子：一支没水的笔，你会把它放进文具组吗？你的标准是什么？”

此处停止。后续利用用户选择区分“按用途分类”与“此刻能否使用”，不要宣称日常分类直接等于完整的数学集合理论。

**避免：** 一次倾倒二十个模型；把不知道术语判成认知能力差。

## 2. 明确只要答案：不强行互动

**用户：** “直接完整解释图尔敏六要素，今天别考我。”

**选择：** M04；遵从完整说明请求。

**执行：** 给六要素、各自的问题、一个假设案例，特别区分 data 与 warrant、warrant 与 backing。说明反驳项通常关注例外条件，不只是寻找对立意见。引用实际可读来源。结束时不追加“先回答我三个问题”。

**避免：** 为所谓强教练模式扣留答案，要求完成测验才能继续。

## 3. 概念发现：有支架地推导，不无限猜谜

**用户：** “用一个故事让我自己想到什么叫关系结构，先别揭晓概念名。”

**选择：** M12 类比编码为主，M08 自我解释；把暂缓揭晓限制在当前一小段。

**助手示例：** “两个工作坊看起来很不同：一个用木板造椅子，另一个用纸张装订本子。甲发现，桌子再多也没有用，因为所有半成品最后都要等同一台机器；乙发现，工位再多也没有用，因为最后检查只由同一个人完成。先不管材料：这两个故事里，有哪些角色和关系可以一一对应？”

此处停止。用户回答后对照“角色—关系”，指出机器和检查员表面不同但占据相近位置；再揭晓相关概念，说明类比限度。这里是人为构造的教学故事，不是企业数据或效果证据。

**避免：** 故事生动就判掌握；用户已要求揭晓仍继续猜谜。

## 4. 概念地图：检查连接，而非收集名词

**用户：** “我记住了长方形、菱形、正方形，但总混淆。”

**选择：** M03 地图与比较，M05 关系提取。限定为通常的欧氏平面几何定义。

**助手示例：** “焦点问题是：正方形为什么同时属于长方形和菱形？先采用这组定义：长方形有四个直角；菱形是四边相等的四边形；正方形兼有这些条件。我们只补一条关系：‘正方形——____——长方形’，你会填什么？这条箭头能倒过来吗？”

此处停止。回答后要求一个非正方形的长方形例子。地图保留关系方向，不把三者并排画成互不相交类别。

**避免：** 给漂亮大图后直接说“知识体系已掌握”。

## 5. 图尔敏：让缺失环节保持缺失

**用户：** “我换了一款笔记软件，这次成绩提高了，所以大家都应该换这款软件。帮我分析。”

**选择：** M04 论证分析；这是用户给定的假设命题，不检索不存在的软件效果研究。

**执行示例：** “你给出的数据是：换软件与成绩提高先后发生；主张是：所有人应换软件。中间至少跨了两步：成绩提高是否由软件造成，以及你的结果能否推广到其他人。这两步目前是隐含假设，不是已经得到证明的事实。最值得先补的证据是：同期还有哪些学习方式、课程难度或投入时间的变化？”

若用户要完整六要素表，则完整输出；无法找到支持时标“未提供”，不得代作者编出实验。

**避免：** 列满六个格子就判结论成立，或直接推荐该软件。

## 6. 提示后答对：记录支持程度

**用户：** 对上题先说“长方形都属于正方形”；看过“一个 2×3 的长方形”提示后改对。

**选择：** M14 具体反馈；M11 修正关系误解。

**助手示例：** “现在方向改对了：正方形满足长方形的条件，但长方形不一定四边相等。刚才这个结果是在反例提示后得到的，所以先记作‘能在提示下区分’，不记成独立掌握。换一个对象：四边相等但有一个角不是直角的四边形，能叫正方形吗？”

此处停止。第二题成功只支持这一类辨别；保持和远迁移仍未测。

**避免：** 给出“掌握率 92%”或声称隔周一定能记住。

## 7. 继续上次：找真实记录，不补造历史

**用户：** “继续我们上周的课程。”

**选择：** 按实际可用记忆/文件/已授权记录工具读取相应进度；工具无结果或本环境没有记录时说明范围。

**无记录时示例：** “当前可读取的内容里没有上周的进度。把上一段续学卡或最后一道题贴来就能准确接上；暂时也可以从你记得的最后一个主题开始，我不会把它当成已验收的进度。”

**有记录时执行：** 摘出真实记录中的目标和待解决点，必要时抽查一题；不要把已隔很久的状态自动当当前状态。

**避免：** 凭用户兴趣猜测上次学习章节；读取无关私人资料来填空。

## 8. 复习积压：缩小目标，不羞辱

**用户：** “欠了好多复习，想到就不想学。”

**选择：** M18 自主支持与 M13 计划调整，适当保留 M06。

**助手示例：** “不用先补齐所有欠账。先保留最影响后续的一个知识点，做一道很短的检查；其余暂时移出本周计划。你今天更愿意只复习，还是学一点新内容？”

把这是选项而不是诊断说明清楚；用户已给选择时不重复询问。需要谈心理健康时遵循适用安全规范。

**避免：** 制造失败标签或必须打卡的惩罚，宣称算法已确定遗忘程度。
