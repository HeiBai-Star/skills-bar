# 概念地图、图尔敏论证与追问

依据：M03、M04、M08、M10；来源 S03、S04、S05、S10、S12。以下流程与示例为本包的教学改写。

## 概念地图协议

先明确焦点问题，例如“如何判断一次练习反映理解还是模仿？”再选解释该问题所需的少量概念。初图可从 5–9 个节点起步，这是可调整的显示约定，不是认知容量定律。

每条边必须组成可读命题：
`概念 A — 具体关系词 [条件或限定] → 概念 B`

按需使用“包含、是……的必要条件、与……对比、用来测量、在……条件下影响”等关系。不要用无信息的“相关”覆盖所有边；没有证据不要擅用“导致”。仅画树状分类不能代表完整概念地图。

把关键边的来源、适用范围或待核实状态记录在图外的关系表，保持图面清楚。只有真实存在跨区关系时才添加跨链接，不能为了好看编造连接。

教学时选择一种活动：用户补一个关系词、删掉错误边、解释一条跨区联系，或看过示范后闭卷重建。不默认由助手一次画完再夸用户“掌握了”。

验证关系正确性、方向、条件和焦点问题覆盖度，而非节点数量。读不到用户上传图的细节时先取得可读图像或文本，不猜线条。

文本优先格式：焦点问题 + 三元组 + 待确认边。用户要求图片/可视化时按环境实际工具生成；可用 Mermaid 时用简短标签并给文字替代，不声称未验证的代码已渲染成功。

## 图尔敏协议

先原样保留或准确转述待分析主张。阅读时区分“作者明确说了什么”与“为了完整分析暂时补出的前提”。不要替作者编造证据。

| 元素 | 需要回答的问题 | 易犯错误 |
|---|---|---|
| C 主张 | 到底要支持哪个有范围的结论？ | 把话题名当结论 |
| D 材料/证据 | 已观察或引用了什么？来源在哪里？ | 把主张换句话写成证据 |
| W 保证 | 为什么这些材料能够支持该主张？ | 把“因为有数据”当连接原则 |
| B 支持 | 哪些依据支持该保证本身？ | 只继续堆同一类型的个案 |
| Q 限定 | 推断有多强、适用哪些对象和条件？ | 随便填写虚构概率 |
| R 例外/反驳条件 | 在什么情况下，即便有这些材料也不能这样推出？ | 只写泛泛的反对意见 |

完整分析先重建 C/D/W，再查 B/Q/R。教学入门每次只练一个薄弱环节，不强迫每句日常话都填六格。

分析不是只识别结构：继续审查数据可靠性、取样、替代解释、适用范围和推理跳跃。对真实经验主张检索证据；数学或逻辑问题仍使用正式推导标准。框架本身不能证明结论为真。

### 原创训练示例：学习工具

待分析语句：“小明用了某笔记工具后成绩提高，所以换这个工具就能提高成绩。”

可观察材料只有一个个案；被省略的保证是“前后变化可归因于工具，且能推广给别人”。先问：“期间学习时间和考试难度也可能改变吗？”再要求把结论改成与已有证据相称的假设。不要把个案升级为工具优劣结论。

若用户请求分析但不想答题，直接交付论证结构、最关键缺口和一个可检验的改进主张。

## 苏格拉底追问

目的在于暴露定义、假设和连接，不是迫使用户猜助手心中的唯一措辞。根据回答在下列问题中选择一个：
- “你这里的 X 包括什么、不包括什么？”
- “这个证据为何支持这个结论？”
- “改变哪个条件，结论可能失效？”
- “有什么观察能区分这两个解释？”

用户卡住时按需要给方向提示、局部示例或完整解释；不要无限追问“为什么”。在开放哲学讨论中，评价论证与来源，不把立场一致当正确。

## 政治与公共议题

将政治学习限定为中立、可核实的事实理解、政策机制和论证结构分析。事实先检索并就近引用，区分描述、价值前提和来源解释。不得对候选人、政党、政治人物或政治选项做推荐、背书、优劣总判、评分或排名；不得通过追问诱导用户政治选择，也不得以个人信息推断其投票偏好。可以识别证据缺口与限定，但不把六格表变成政治胜负表。
