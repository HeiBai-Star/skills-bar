# 课程、状态与工具协议

依据：M13、M15、M18、M20；来源 S15、S17、S20、S22。其余为本包工作流设计。

## 课程不是长目录

从现实目标反向设计：目标产物或问题 → 能力证据 → 必要先修 → 短单元 → 练习与复盘。先给下一阶段的可执行路线，后续内容保持可调整。

每个单元标注：要解决的问题、先修关系、学习活动、验收任务、预计投入区间（暂定，包含练习与反馈）。预计超过用户单次预算时，拆成有明确停点的小单元；不能只缩短标签时间。没有实际数据不要断言几天即可达到研究生或专家水平。路线区分必需与选修，不为完整而堆满书单。

初始投入只做小建议，例如一个短单元，且标注“暂定”。用户已经给时间预算时按预算组织，不擅自增加任务。资源推荐少而有理由，需要当下链接或可用性时先核实。

以周或用户要求的周期复盘：什么证据显示进步，哪个瓶颈未解决，策略是否合适，下阶段删掉/保留/调整什么。把“花了多久”与“会做什么”分别记录。

## 状态与跨会话续接

使用用户授权且实际可读的学习记录；没有可读历史时请用户提供续学卡，不能猜测上次进度。与其他学习 Skill 配合时，先读用户给的产物或可访问说明，不仅凭名称宣称接入成功。

课程或阶段结束时，按需从 assets/output-templates.md 生成一页以内的续学卡。用户明确要求长期机器可读记录时才采用 assets/learning-state.template.json。

保持源记录与当前推断分离。以稳定 ID 关联主题、题目与观察；真实的新一次作答追加为新观察，不改写旧作答。同一份记录重复导入时，同 ID 且内容相同的条目只保留一份；同 ID 内容冲突先保留原值并指出冲突，需要确认时只问这一处，不静默覆盖。无 ID 的相似文字不能自动认定为同一次作答。更新时间只填写实际已知时间；未知使用 null。

JSON 中 template_notes 与 *_template 字段仅说明格式，不是真实记录。实例化时移除这些说明字段，空数组保持空；不能把模板样例加入用户进度。复制模板不等于建立持久数据库。

续学时先核对目标是否变化，互动模式可抽查一个关键知识点；用户只要总结或不愿作答时遵从请求，不把旧状态当作本轮新验证。用户更正记录时保留必要修订信息并尊重其隐私选择。

### 状态字段与词表

下表是唯一的状态映射。中文用于对话和续学卡，代码用于 JSON `competencies[].status`；状态不是高低阶梯，也不是各维度共用的总成绩。

| 状态码 | 中文展示名称 |
|---|---|
| `not_tested` | 未测 |
| `needs_support` | 需支持 |
| `independent_current` | 能独立完成本类任务 |
| `retention_evidence` | 有延迟保持证据 |
| `transfer_evidence` | 有迁移证据 |

- `evidence_kind`：`user_report`、`observed_performance`、`tentative_inference`。用户追述昨天的答题是自述，不能改成现场观察；助手推断写入 `interpretation`，不能补造 `actual_user_response`。
- `support_level`：`independent`、`directional_hint`、`partial_steps`、`full_demonstration`。答对不自动表示独立；支持情况不明填 `null`。
- `dimension`：`recall`、`concept_discrimination`、`relational_explanation`、`procedure`、`argumentation`、`transfer`、`self_calibration`。
- `retention_tested`／`transfer_tested`：`true` 仅表示有做过相关检验的记录，不等于成功；明确未测用 `false`，是否测过未知用 `null`。
- `retention_scope`／`transfer_scope`：对象 `{"details": "有依据的范围与结果", "evidence_ids": []}` 或 `null`。保持范围写已知间隔与任务，迁移范围写熟悉/新情境、相似度和结果；只知跨了一个日历日不能写精确 24 小时，未测与未知不能补造范围。
- `status` 根据目标维度与证据选一项当前摘要；保持和迁移可同时存在，以各自范围与证据保留，不因摘要只能填一项而覆盖另一项。测过但答错不标为正向保持/迁移证据。`not_tested` 不要求虚构一条作答来支撑。
- 未知用 `null`。`evidence_ids` 只关联实际 `observations`，`source_ids` 只关联实际 `sources`；用户来源建议用 `SRC-` 前缀，避免与理论来源 S01—S23 混淆。

### 复习队列生命周期

`review_queue` 只保存尚未完成、尚未取消的事项，成绩留在 `observations`。`closed_reviews` 保留原复习项的已知内容，并加上 `resolution`（`completed`／`cancelled`）、已知关闭时间、相关观察及尚待处理的提醒动作；不额外保存完整事件日志。

1. **创建与去重：** 先检查 `topic_id`、`target_dimension` 及 `rationale` 中的实际目的与范围；重复安排同一复习时更新原项，不生成新 ID。目标不同（例如同类解题与应用迁移）的项目可以并存。合并旧记录时，已在 `closed_reviews` 的 ID 不得重回队列；同 ID 的相同关闭记录也只保留一份。新一轮复习另用新 ID，不能靠导入旧卡隐式重开。
2. **完成：** 有真实作答就新增观察并填入该项 `review_id`，写入关联该观察的 `completed` 关闭记录，再移出队列。用户仅说“做过了”也可记为 `user_report` 后关闭，但题目、答案和成绩未知，不推断成功。完成一项不代表同主题其他项完成，也不自动取消后续复习。
3. **取消与改期：** 明确取消则记 `cancelled` 后移出队列，不编造作答；改期保留原 `review_id`，更新已知时间窗口与理由。产生新的后续复习时使用新 ID，并在理由中引用触发它的观察。关闭记录只保留一份当前处理结果，不需要完整事件日志；用户明确更正关闭状态时保留修订依据，不能靠较旧导入覆盖。
4. **外部提醒：** 修改或移除 JSON 项目不会修改日历/调度器。已有提醒时，仅按用户要求及实际工具更新或取消并核对；未要求变更则不擅自停止提醒。`reminder_reference` 和 `actual_tool_confirmation` 只填工具实际返回的标识/结果，不因改了本地日期而清除旧确认或伪造新确认。移出队列时把这些信息保留在关闭记录；用户要求但尚未成功的同步动作写入 `pending_reminder_action`，成功后才清空。改期仍在队列时，将未同步事项写入理由并说明实际差异。

### 旧记录兼容

学习状态格式为 `2.0.0`，技能包版本与记录格式版本分别管理。只在用户要求导出或更新记录时生成转换后的副本；只读续学可直接解释旧记录，不自动覆盖文件。

读取 `1.0.0` 时按上表及以下兼容名称转换 `status`：`未测` → `not_tested`；`需支持`／`需要支持` → `needs_support`；`能独立完成本类任务`／`当前可独立完成` → `independent_current`；其余两个中文名称分别对应 `retention_evidence`、`transfer_evidence`。保留原有 ID、题目、回答、来源及日期。未知状态写 `null`，在 `limits` 保留原值，不能凭名称升级能力。

旧记录缺少的 `review_id`、`reminder_reference` 及范围字段填 `null`，缺少 `closed_reviews` 时设为空数组，不虚构历史关闭事件；若现有证据已明确范围，可据实补入并关联证据。只有旧布尔值时保留其值，但在 `limits` 说明范围与成败尚未核实，不补写题目或日期。若未完成兼容转换，不把未知版本标成 `2.0.0`；未知版本保留原始内容，列出能可靠读取的范围。

## 工具能力分层

**基础层：** 依当前对话进行讲解、题目、反馈、文本概念关系、学习路线和可复制续学卡。无需连接器或代码。

**检索与材料层：** 仅在真实提供的网页/文件工具中检索。说明可读材料范围、版本和时效；无法获取全文时只描述已知部分并请用户提供相关内容。不要伪造文件引用或页码。

**产物层：** 用户要求图、代码、PDF、文档、表格时使用环境相应工具及技能；脚本需实际运行才能宣称通过。不能从文件标题猜下载路径。

**外部记录层：** 用户明确要求后才写日历、笔记或其他系统；调用实际工具并确认写入结果。未授权时不写入；缺少外部能力时按环境规则发现可用连接器或插件，不擅自安装或授权；确无可用能力时给文本。

**提醒层：** 建议复习时间不等于已创建提醒。只有可用调度工具成功建立任务才可报告提醒已设置；不能宣称离线主动工作。

技能包是教学说明，不创建账号，不内置密钥，不默认上传私人笔记。绑定具体外部服务时使用环境允许的发现流程，不杜撰接口。

## 输出节奏

快速解释：直接答案、一个关键例子、必要边界；用户不要求互动时不追加测试。

互动教学：本轮目标、最小讲解或提示、一项用户任务，然后暂停。

完整教材：按用户所需长度连贯展开，练习与答案分区；允许不实时互动。

深度研究：先界定问题和资料范围，区分研究结论、推理与争议，给来源和未解决问题。

收尾：任务完成就结束；只在有帮助时给一项下一步，不重复列出全部模式。
