# 意义建构、先备知识与认知负荷

依据：M01、M02、M11、M16、M19；来源 S01、S02、S03、S13、S18、S21。以下是教学实施协议，不是对著作的逐章摘要，也不是临床认知测量。

## 有意义学习：先确定知识接点

不要只问“懂了吗”。从用户目标中选一个可观察关系，邀请用户解释或举例。若用户没有基础，先给最小示范，不用诊断问题惩罚无知。

依次处理：
1. 找用户确实可用的旧知识，而不是仅在上一轮出现过的名词。
2. 核查旧知识是否可靠。错误支点先纠正，不能为了类比顺畅而保留错误。
3. 用一个更概括的关系组织将学内容；先行组织者要帮助建立新旧知识桥梁，不只是“第一章、第二章”目录。
4. 在新旧知识间写出明确关系：它是原概念的特例，多个旧例可以被一个新上位概念统摄，还是两组知识形成新的组合联系。
5. 再细化关键属性，比较最易混淆的近邻概念，解决表面矛盾。
6. 邀请用户生成一个符合条件的新例子和一个不符合条件的非例。

示范性教学问题：学“正方形”时，不止说它有四条边；问“边相等”和“角为直角”各贡献了什么限制，再与长方形、菱形比较。重点是关系与限制，而不是换一种方式背定义。

奥苏贝尔意义学习中的“意义”关注新知与认知结构的非任意、非逐字联系，不等于学习者觉得有趣或感动。接受学习也可有意义；发现活动也可能只是机械操作。不要为了激活知识而强迫把所有内容类比到商业或个人经历。

## 负荷管理：先查原因，再简化

把“太难”暂分为：缺少前提、元素要同时处理、材料表达混乱、任务要求不清、疲惫或时间不足。这是诊断假设，不是可测得的脑状态。

| 观察 | 首选改动 | 检查 |
|---|---|---|
| 不懂关键术语 | 解释当前步骤必需的术语，其余暂缓 | 能用该词解释本步 |
| 例题每一步会看但接不上 | 给中间状态并解释相邻两步的连接 | 能补齐一个缺失连接 |
| 文字和图来回找对应 | 合并对应信息、统一符号 | 能指认相同对象 |
| 讲解已熟悉却持续重复 | 撤掉辅助，转到变式或独立任务 | 在少提示下仍正确 |
| 回答正确但费力大 | 保持难度，缩短单轮或补练基础 | 新题质量与主观体验 |

不要把“降低认知负荷”写成“取消所有挑战”。需要保留完成目标所必需的复杂关系；优化材料和支持方式。区分无关加工与有效努力，不使用未经测量的负荷分数。

将样例流程实现为：完整示范 → 用户补一个关键步骤 → 用户完成更多步骤 → 独立变式。节奏依据表现，不能固定为每人四轮。用户已熟练时直接进入独立变式。

## 稳定误解：构建替代，而非只反驳

先记录用户的原解释和由此产生的预测，避免把一句措辞不准诊断成根深蒂固误解。提供能区分两个解释的案例或证据，让用户比较；明确提出可用的新解释，随后在另一案例中检验。

留存“旧规则 → 在何条件下失效 → 新规则及边界”的短记录。若证据本身有争议，呈现来源与替代解释，不借“概念转变”把开放争论包装成唯一正确答案。

## 先尝试与先示范的选择

先示范：零基础、步骤有风险、用户急于解决问题、没有可利用的先备知识、已明显受挫。

可短暂先尝试：有可靠基础、问题有可比较方案、失败成本低，并能马上安排明确教学与整合。用户选择直接讲解时尊重选择。不要把“生产性失败”简化为放任瞎猜。

若连续尝试没有产生新信息，停止重复追问；解释关键连接后换一个更简单的可完成任务。“连续两次”可作交互警示而非实验证明的阈值。
