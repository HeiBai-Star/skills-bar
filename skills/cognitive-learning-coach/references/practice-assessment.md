# 练习、反馈、复习与迁移

依据：M05–M08、M12–M17、M19–M20；来源 S06–S10、S14–S19、S21–S22。所有次数、间隔、标签为本包可调整的操作默认值，不是心理学常数。

## 先把目标变成任务

| 目标 | 合适任务 | 不足的替代 |
|---|---|---|
| 准确提取事实 | 无提示回忆关键内容 | 仅表示“看过” |
| 区分概念 | 边界例、非例、相似案例判别 | 只复述术语 |
| 解释关系 | 说明关键连接和改变条件的后果 | 原样背段落 |
| 执行技能 | 少提示完成新任务并检验结果 | 复制助手产物 |
| 审查论证 | 找证据到主张的缺口并限制结论 | 写满图尔敏标签 |
| 迁移 | 在新场景选择模型并说明失效条件 | 给旧题换名词 |

一轮互动通常出一道核心题。用户明确要求题库时可以批量输出，并把答案分开；没有用户回答就不生成成绩。练习题要有足够信息，开放题给评价维度，存在多种正确答案时承认等价表达。

## 支持程度与答案时机

零基础先示范；已有初次学习再提取。需要答案时遵从用户请求。训练期间不要在题干里偷放答案，也不要在用户尚未作答时同时展示完整标准答案。

记录支持程度：独立、方向提示、局部提示、示范后模仿。只对当时真实观察到的表现下结论。

## 反馈协议

用“具体正确处 → 一处关键差距 → 可执行修订 → 小型复测”组织反馈。先判内容和方法，再看信心。把不确定的答案核实后再评价，助手不能凭口气自信当裁判。

对猜中但解释错误、照抄成功、依赖提示的作答分别标注。没有必要把每题都打分；用户要求分数时公开任务标准和依据，不能声称这是心理测量或能力概率。

若用户不愿做题，交付所需讲解，只记“本轮未新增验证”，保留历史状态、证据与日期；没有历史证据时才记未测。不用“未掌握”惩罚选择。

## 建议性的间隔复习

先问或读取目标保持期与实际可用日程。没有资料时只提出可调整的起步计划，不称为个性化最优遗忘曲线。

| 最近证据 | 建议动作 |
|---|---|
| 理解错了或完全提取失败 | 先纠正或补前提；稍后换例再试，下一可用学习时段优先检查 |
| 提示后才正确 | 较短间隔后用少提示新题检验 |
| 独立正确但脆弱 | 可在约 1–3 天内再测；按目标与日程修改 |
| 已有多次跨天独立成功 | 可以拉长到约一周或更久，并混入迁移题 |
| 只做过当场检查 | 明写“长期保持未测”，不能直接跳到长期稳定 |

这些时间是起步启发式，不是 S08 直接给出的通用处方。若用户已有真实间隔重复系统，以其记录为基础，不假称本包实现了 FSRS/SM-2。

复习积压时按关键前提、已观察到的错误、时间要求和可用时间排序，不用累积惩罚。处理当天能承担的少量任务，剩余重新安排。当前日期/时区不明就使用相对时间或询问，不编造绝对日期。

## 交错与迁移

有基本规则后再混合容易混淆的类别。让用户先判断应采用哪个方法以及理由；不要把随机在多个学科间跳转当交错学习。

迁移练习使用：熟悉例子 → 与它结构相关的新例子 → 表面相似但不适用的例子。要求说明哪些条件保持、哪些改变。只成功完成近迁移就记近迁移，不夸大为通用批判思维提高。

## 有证据的进度

每条记录包含目标、实际题目、用户回答的关键片段、支持程度、反馈、日期或未知、下一次检查。未获得作答的数据留空。

能力维度彼此独立，使用 [统一状态词表](planning-state-tools.md#状态字段与词表)。表现结论须追溯到观察；“未测”不要求编造观察。记录保持/迁移的已测范围和结果，不能把“做过测试”当作“测试成功”，不输出无依据的“掌握度 93%”。

课程继续前检查真正必需的前提，非关键知识可以并行补。验收标准在练习前说明，不在用户答后移动标准来营造失败感。
