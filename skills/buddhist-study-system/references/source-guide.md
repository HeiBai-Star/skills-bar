# 来源入口与阅读指南

这是选书、查出处和安排精读的导航，不是预装的经论全文库。阅读次序属于本系统的教学建议，不是宗派判教。先选择一部主文本和足够小的问题，再增加注疏与研究材料。

## 来源使用次序

默认使用 **佛教原典 → 传统注疏 → 现代佛教学术研究 → 权威工具书 → 普通网络解释**。同一网站可能同时收录这五类内容，必须按具体材料分类。现代法师讲记应依内容作为具名传统解释或现代研究使用，不能仅因年代新就归为学术定论。

| 入口 | 用途 | 使用时记录 |
| --- | --- | --- |
| [CBETA Online](https://cbetaonline.dila.edu.tw/) | 汉文经论、注疏和部分近现代著作的检索与阅读 | 藏经编号、题名、卷品、页栏行及文本层次 |
| [CBETA 官方 XML 文本](https://github.com/cbeta-org/xml-p5) | 核对题名、题署、正文与校勘结构；网页无法提取正文时的替代来源 | 文件与版本；不要把 XML 标签或校勘异文混入正文 |
| [SuttaCentral](https://suttacentral.net/) | 早期佛教文本、不同语言译本及平行材料的查找入口 | 经号、语言、译者；平行关系须打开相应记录确认 |
| [Access to Insight 经藏入口](https://www.accesstoinsight.org/tipitaka/) | 阅读带经号和译者信息的巴利经文英译 | 译者、版本及站点标出的更新提示 |
| [84000 学术阅读入口](https://scholar.84000.co/) | 藏文佛典相关译文、目录、术语与对读资源 | 目录号、译本和文本语言；英译不是藏文原词本身 |
| [臺大佛学数位图书馆](https://dlbs.liberal.ntu.edu.tw/) | 检索研究书目与可取得的论文 | 作者、出版信息、是否实际取得全文；书目命中不等于读过论文 |

这些入口不是质量一致的单一权威；单个论点仍需定位到具体经文、注疏或研究。某网站无法访问时，可换该机构公开的文本或用户提供材料，不能把“网页可打开”当成“正文已核验”。

## 入门与专题候选

解释与练习默认用中文。外语原文／译文是对读资源，不要求学习者先学会巴利文、梵文或藏文。

### 早期佛教与阿含

以一篇短经为单位，先看问题、说话者和推理，再讨论跨传统关系。

| 材料 | 建议用途 | 版本与边界 |
| --- | --- | --- |
| 汉译《杂阿含经》等阿含材料 | 从五蕴、无我、缘起等专题选段，作为中文学习的早期文本入口 | 在 [CBETA](https://cbetaonline.dila.edu.tw/) 核定具体经号与卷次；本指南不预填与巴利经的逐一对应 |
| [SN 56.11，转法轮经，Thanissaro 英译](https://www.accesstoinsight.org/tipitaka/sn/sn56/sn56.011.than.html) | 四圣谛、八正道；比较教说与相应任务 | 引用该译本时具名，不把工作中文译述称为古代汉译 |
| [SN 22.59，无我相相关经文，Thanissaro 英译](https://www.accesstoinsight.org/tipitaka/sn/sn22/sn22.059.than.html) | 围绕五蕴检验关于“我”的判断 | 核对自身、可支配性等理由的关系，不直接挪成全部中观论证 |
| [SN 12.15，Kaccayanagotta Sutta，Thanissaro 英译](https://www.accesstoinsight.org/tipitaka/sn/sn12/sn12.015.than.html) | 正见、有无两端与缘起 | 可与后世论典比较，但不抹去年代和问题设置的差别 |

### 藏传与进一步比较

需要藏译对照或藏传解释时，从 [84000 学术入口](https://scholar.84000.co/) 确认题名、目录号与可取得译文。查原典与查某一藏传论师的解释是两项任务；不能把译者导言或一篇目录说明代表为全部藏传的主张。

## 注疏、现代研究与工具书怎么选

先依据当前研究问题选材料，通常一项代表性注释配一项直接相关研究即可。记录作者、传统、所据底本、论证方法和能解决的问题，不把“权威”“大师”“学术”当免检标签。

- 注疏：优先读与当前段落直接相关的部分，标明如何补充、调整或限制原文读法。
- 现代研究：优先可核对原文、译本和论证的期刊论文或学术专著；历史问题看作者使用的写本、目录、语言或传播证据。
- 工具书：先查词条的作者、引证与语境，用于形成检索词；遇到多义词回原文确认。
- 普通网络解释：用于发现疑问或搜索线索；其引文、历史判断和“所有宗派都认为”类说法另行核验。

制作阅读计划时，每项材料都说明“为什么现在读、读哪一小部分、要回答什么问题”。没有核对到版本或可用性时标记待确认，不编造出版社、译者、ISBN、章节和页码。
