# 宗派语境与术语辨析

本文件是一份防止误读的检查表，不是各传统的统一教义词典。回答时仍须回到特定文本、论师和问题。对应文本入口见 [来源与阅读指南](source-guide.md)。

## 先标出讨论层次

需要时用一句话说明：“以下先按某文本／某注释传统解释。”同一传统内部也可能有分歧；不能把时代、地域、经典群、论学体系和宗派组织当成同一层级。

| 范围 | 优先确认什么 | 需要防止的替代 |
| --- | --- | --- |
| 早期佛教／巴利传统 | 当前是经藏、论藏、注释还是现代解释；巴利经文的具体版本 | 将现存巴利传统全部等同于可直接复原的历史佛陀原话 |
| 汉译阿含 | 经号、译本、段落；需要比较时另查平行经对应 | 把某一巴利译文直接充当汉译阿含原文，或默认内容完全相同 |
| 般若经典 | 当前经本、上下文、菩萨道及相关术语 | 将所有空义直接压成后世某一家中观解释 |
| 中观 | 具体论著、本颂与注释层次、论敌、否定对象；后世解释归属 | 用“什么都没有”代替论证，或把空当作背后的终极实体 |
| 唯识／瑜伽行 | 文本及论师；识、所缘、三性与三无性的具体用法 | 仅凭“唯识”二字判成个人随想创造世界，或把所有唯识读法等同 |
| 如来藏相关文本 | 所据经论、比喻、染净关系及注释方式 | 预先把所有文本都解释为永恒灵魂，或预先宣布只是中观换名 |
| 禅宗 | 语录、公案、传记、论说或《坛经》的具体版本及问答对象 | 把教学场景抽离后当普遍形式命题，或把不执文字说成不需学习 |
| 净土 | 经论、愿与行、念佛等词的上下文及具体注释传统 | 只用心理治疗或愿望实现解释净土，抹去传统本身的目标与主张 |
| 藏传 | 具体学派、论师和经论；显教论学与密续语境 | 用“藏传认为”覆盖不同解释；将藏译读法无标记套回汉译 |

覆盖一种传统意味着知道何时定位其材料和解释分歧，不意味着每个问题都要同时介绍全部传统。涉及天台、华严等汉传脉络时照此处理。

## 高风险同词异义

| 词 | 辨析时必须问的问题 | 不可直接作出的等同 |
| --- | --- | --- |
| 空、空性 | 哪些事物“空于”什么？经文、论证还是特定修习语境？此处是否在否定某种自性？ | 空＝不存在；空＝真空或量子场；各传统的空义完全一样 |
| 自性 | 是所破的独立自立、法的特性、唯识三性中的用语，还是汉传特定文本的“自性”？ | 看到“自性”就使用同一否定或肯定定义 |
| 心、意、识 | 普通心理用语还是论典的技术分类？该处实际原词是什么？ | 心＝识＝佛性；心自动等于现代神经科学或精神实体 |
| 佛性、如来藏、真如 | 原文是否区分这些词？关系由哪一注释提出？是在讨论何种成佛、染净或真实问题？ | 三词无条件同义；佛性＝个人不变灵魂 |
| 无我 | 否定何种“我”，如何检验这一对象？人在世俗语言中的指称如何处理？ | 无我＝没有经验、人格或责任；或只等于不要自私 |
| 二谛 | 哪一传统如何使用二谛？两种说法之间的关系如何说明？ | 两个彼此隔绝的宇宙；胜义使日常因果自动失效 |
| 不一不异 | 比较的是哪些对象，“一”“异”各指什么、在哪一层面？ | 所有东西既相同又不同；无需限定语就宣布逻辑失效 |
| 妄、无明、分别 | 指错误认定、认知活动、执取还是特定染净论中的用语？ | 所有思考都是妄，停止判断即理解佛法 |

梵巴词仅作检索候选：梵语 śūnyatā／巴利语 suññatā（空性）、梵语 pratītyasamutpāda／巴利语 paṭiccasamuppāda（缘起）、梵语 svabhāva（自性）。心／意／识可涉及 citta、manas、vijñāna 等词。**这些是常见对应，不证明某段汉译的原词已经查明**；具体词形、译义和技术用法按 [经论研究](text-research.md) 核验，不反向硬套。

## 常见入口问题的处理

### “缘起，所以性空”

如果进入中观论证，先固定被讨论的自性义、缘起义和适用范围。区分因缘产生、部分依赖、概念安立等不同解释途径，不把它们未经说明当作同一个前提。生活中的杯子可帮助发现依赖关系，但“杯子需要材料”本身还不是覆盖一切法的完整证明。用户提出数学对象、无为等反例时，应检查原论证范围，不能用原例重复堵回去。

### “色不异空”

先定位《心经》版本、段落和“色”的当前语义，再说明所采注释。若借《中论》解释，明确这是对读或解释路径，不能当作《心经》自己展开了同样完整的论证。保留经文语境与修学目标。

### “中观空与唯识空到底一样吗”

先把“空于什么”“依什么论证”“如何理解经验”“如何定位修道”等维度对齐。核对三性等词所在文本，不把中观所破的自性直接代换为唯识一切“性”字。可以展示某论师如何调和，也可以呈现真实分歧；不能预设必然一致或必然冲突。

### “妄的本质”“了妄为真”

先把用户语句当待定位的表达，询问或检索它在哪部文本、哪种讲法中出现；没有出处时明确按用户命题讨论。不能因措辞像禅宗就编造经典出处，也不能先假定“妄”后面必有一个实体性的“真心”。区分迷误的对象、迷误活动及对其关系的解释。

## 比较时保留不对称

一边重在分析认知，一边重在说明修道，并不意味着它们对同一问题直接给了相反答案。比较表允许写“此文本未讨论”“暂无可比项”“该解释不代表全宗”。西方哲学和现代心理学的术语只能作为经说明的分析工具，不能把“唯识＝贝克莱”“空＝虚无主义”等标签当结论。

资料检查方向：早期论证看具名经文；般若、中观、唯识、如来藏、禅宗和净土分别看自己的原典与注疏。跨传统结论需要两边的证据，不以一家的判教代替另一家的自我表述。
