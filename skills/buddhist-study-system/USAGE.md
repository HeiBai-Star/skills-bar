# buddhist-study-system 使用指南

这份 Skill 用于长期佛学学习：安排路线、精读经论、辨析概念、检验论证、提问训练，以及整理知识与进度。日常使用时，告诉助手本次想研究什么、希望怎样学习即可。

本指南以助手已经能够读取 `buddhist-study-system` 的完整目录为前提，包括 `SKILL.md`、`references/` 和 `assets/`。仅下载 `SKILL.md` 不能取得完整的课程与训练规则；请使用支持完整目录的导入方式，或补齐其余资源。这里介绍学习用法，不涉及具体平台的安装界面。

## 1. 第一次使用

先发送下面这段，把时间和兴趣改成自己的情况：

> 请使用 buddhist-study-system，帮助我建立长期佛学学习计划。我每周可以投入约三小时，以中文学习为主，对自性、空、缘起和禅宗感兴趣。请不要因为我知道这些词，就假定我已经掌握它们。先给出简明路线、第一周安排和一道诊断题，再根据我的回答调整起点。

首轮应得到可执行的起步安排，而不是要求一次读完的庞大书单。你可以从基础主线开始，也可以从某个兴趣问题进入，再补必要的先修知识。

如果不确定助手是否能读取 Skill，可先说：

> 请确认你能否实际读取 buddhist-study-system 的 SKILL.md 和参考资料。能读取就按它开展学习；不能读取请如实说明。

这份 Skill 已包含角色、课程、研究和训练流程，不需要额外的“助手总提示词”。如有个人交流偏好，可在对话中补充；日常提问只需说明本次任务。

## 2. 日常怎样提问

通常只需要：**研究对象 + 本次任务**。宗派、版本、难度和互动方式会影响结果时再补充，不必每次填写完整表格。

简单问法：

> 请使用 buddhist-study-system，解释什么是自性。

更明确的问法：

> 请在中观语境下解释“自性”。按初学者水平讲，先给直觉解释，再说明论证，最后指出一个常见误解。重要观点请注明出处；没有核实的部分要说明。

如果讲解不合适，可以直接调整：

- “减少术语，先用一个例子解释，并说明这个例子的局限。”
- “提高难度，补充原文、前提和反对意见。”
- “这次只处理这个问题，不展开完整课程。”
- “先解释我贴出的这段话，不要跳到其他宗派。”

## 3. 十种常用任务

下面的句子可以直接发送；这些是自然语言指令，不是必须照写的命令格式。

| 想做什么 | 可以这样说 |
| --- | --- |
| 系统讲解 | “解释缘起与无常的关系，明确语境，给出依据，并指出两者不能直接等同的地方。” |
| 经论精读 | “精读下面这段经文，区分原文、白话释义、注疏解释和你的分析。先核对版本与上下文。” |
| 宗派比较 | “比较中观与唯识如何讨论‘空’，先说明各自选用的文本和术语，不要预设两者完全一致。” |
| 哲学论证 | “分析‘缘起所以性空’的论证，列出定义、前提、关键推理、最强反对意见和结论的适用范围。” |
| 苏格拉底问答 | “只通过提问带我研究无我，一次一个问题，等待我回答，不要提前给结论。” |
| 反方辩难 | “我的理解是：……。请先准确复述，再站在反方提出一项最关键的异议，等我回应。” |
| 知识地图 | “把我们已经讨论的缘起、无我、空和二谛整理成知识地图，标明语境、关系类型与依据；未解决的关系保留为问题。” |
| 阶段复习 | “根据这份学习记录安排复习，先让我独立回答，不附参考答案，再根据表现反馈。” |
| 学习路线 | “按我每周三小时的安排，制定十二周起步计划，每周包含目标、短篇阅读、练习和进阶依据。” |
| 阅读计划 | “围绕自性与缘起安排阅读顺序，说明每次读哪一小部分、为什么读，以及要回答的问题。” |

一次通常选择一个主要任务。需要组合时，说明顺序，例如“先讲解，再让我独立作答，最后反馈”。

## 4. 检查理解与不揭答案训练

**想直接得到评价**，可以说：

> 我的理解是：“无自性意味着事物完全不存在。”请检查这句话，直接指出问题、理由和需要修正的地方。

**想自己推导**，可以说：

> 我正在研究“无自性是否意味着不存在”。不要直接告诉我答案，只提问，一次一个问题，根据我的回答推进。

提问训练中，你可以随时调整：

- “给我一个更小的提示，但不要说出结论。”
- “换一个例子，让我自己判断。”
- “指出我哪一步需要重新检查，先不要替我修正。”
- “现在退出提问模式，直接解释，并告诉我卡在了哪一步。”

“提示一下”“继续”“我不知道”不等于要求揭示答案。如果想直接听解释，就明确说出来。助手也不应在总结或知识地图里提前放入待推导答案。

## 5. 精读一段或一本经论

尽量提供原文、可读取的文件或链接，并说明题名、译者或版本；不知道版本时可以请助手协助辨认。只有一段文字，也可以先做局部分析。

单段精读示例：

> 请精读以下原文：……。我使用的版本是……。先确认这一段在讨论什么，再解释关键术语、句法和论证。分清原典、注疏与现代解释，最后给我一个理解检验问题。

整本精读示例：

> 我想系统精读《中论》。请先确认可读取的版本和目录，建立分段阅读计划。今天只完成第一个适合的论证单元，区分本颂与释文，并记录下一次的起点。不要把未读章节记成已经精读。

整本阅读可以跨多次对话推进。每次保留版本与阅读位置，比不断让助手重新概述全书更便于续接。只有书名、没有可读正文时，可以先安排路线；逐段精读仍需要取得文本。

## 6. 一次学习怎样安排

可以用下面的三十分钟安排试行，再按难度调整：

| 时间 | 做什么 | 可以发送的指令 |
| --- | --- | --- |
| 前五分钟 | 回忆上次内容 | “依据记录问我一个复习问题，先不要提示。” |
| 接着十分钟 | 学一个概念或读一小段 | “今天只处理这个问题：……。” |
| 再十分钟 | 自己解释、重构或应对反例 | “现在让我独立说明，你检查定义和推理。” |
| 最后五分钟 | 整理收获和下一步 | “生成本次续学卡，区分已经做到的与仍需提示的部分。” |

时间不够时缩小材料范围。学习进度要看自己能否解释、举例、应对异议，以及过一段时间后是否还能重建理由。

## 7. 保存进度与换对话续学

学完一个完整单元后，可以发送：

> 请生成本次续学卡：包括学习目标、文本版本与阅读位置、当前模式、我的实际理解与提示程度、未解决的问题、下次第一个任务和待复习项目。只记录实际完成的内容。如果仍在不揭答案模式，不要写入尚未推导出的答案。

如果希望保存成文件，再补一句：

> 请把记录保存为“佛学学习记录.md”；如果当前不能生成文件，就给我可复制的 Markdown 正文。

换到新对话时，带上这份记录并发送：

> 请使用 buddhist-study-system，读取以下学习记录，从“下次第一个任务”继续。先复习一个关键点，不重复安排整套入门课程。我的目标如有变化，会在这里补充。

Skill 提供记录和恢复流程，但不能保证不同对话自动共享进度。以实际可读取的记录为准；没有旧记录时，可用最后读过的文本或记得的问题重新定位。

复习任务可以安排在下次学习、约一周后或约一月后，按表现调整。记录中的复习安排本身不是自动提醒。

## 8. 回答偏离需求时怎样纠正

| 发现的问题 | 可以直接这样调整 |
| --- | --- |
| 讲得太抽象 | “用一个具体例子解释，再指出类比不能覆盖的部分。” |
| 混用了宗派概念 | “暂停，分别说明这些词在各自文本中的含义，再比较。” |
| 只有结论，没有依据 | “这一判断来自哪段原典或哪位注释者？请给可核对的定位，未核实就标明。” |
| 一味赞同我的理解 | “请找出这段理解最可能失败的一步，给出有力反例。” |
| 在训练中提前给了答案 | “恢复不揭答案模式，从我尚未完成的一步继续，每轮只问一个问题。” |
| 回答太长或跑题 | “这次只回答我提出的核心问题，保留必要理由和出处。” |
| 宣称我已经掌握 | “请说明依据是我的哪次实际作答，再给一个新情境检验。” |

## 9. 现在就开始

如果想从“自性与缘起”进入，第一句可以用：

> 请使用 buddhist-study-system，从“自性与缘起”开始带我学习。先用中观语境给一个适合初学者的简短讲解，说明需要哪些先修知识；然后让我用自己的话解释，再根据我的回答决定下一步。今天先完成一个小问题。

如果更希望自己探索，就把它改为：

> 请使用 buddhist-study-system，通过苏格拉底提问带我研究“自性与缘起”。先了解我怎样理解自性，一次只问一个问题，不提前告诉我结论。
